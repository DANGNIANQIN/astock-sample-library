历史 ST 状态：为什么「拿一份 ST 名单」永远是错的

做 A 股回测，只要涉及「剔除 ST」，就必须知道 每只票在每个历史交易日是否处于风险警示。绝大多数数据源只给当前名单——包括交易所行情软件和主流第三方。

一、单快照错在两个方向，不只是「不全」

错误方向机制我们库里的实测（2021-01-04→2026-11-26，7,308,957 行 / 5,874 只）
回填过头今天是 ST 的票，被当成「历史上一直 ST」312 只被标 ST 的票里 0 只有过摘帽（6 年零解除风险警示，真实市场不可能）；其中 86 只 / 2,227 行在 2026-08 前出现 |涨幅| > 11%，最大 95.78%——5% 限幅下物理上不可能
整段丢失曾 ST、已摘帽的票，历史 ST 段全没了261 只 / 5,918 天可证实的 ST 日完全不在名单里。例：600599 2021–2025 每年最大日涨跌 = 5.12 / 5.05 / 5.03 / 5.04 / 5.06，整五年按 5% 限幅运行，但现名不带 ST，历史记录为 0

二、价格本身就带信息：ST 日可以重建出「下界」

主板风险警示股涨跌幅 5%、普通股 10%。所以：

某日 close == round(preclose×1.05, 2)  且  close == high
⇒ 当日限幅必为 5% ⇒ 当日处于风险警示

单条判据会有巧合（稳健大盘股偶尔恰好收在 +5.00%），所以加三重闸：

  1. 上面的封板判据；
  2. 该日前后各 10 个交易日内 max(high/preclose−1) ≤ 5.15% 且 max|涨幅| ≤ 5.15%（真 10% 的票在 21 天里几乎必超）；
  3. 同票同段（相邻 ≤60 自然日）命中 ≥2 天。
实测产出数字
可证实 ST 段 / 只数 / 天数（2021-01-04 → 2026-07-31）902 段 / 414 只 / 9,527 天
假阳性标定（20 只从未 ST 的白马：600519 等）命中 0 只
静态名单遗漏的量261 只 / 5,918 天
边界（引用时必须写）：① 只能证「是 ST」，不能证「不是 ST」；② 只覆盖 2026-07-31 之前——2026-08-03 起主板 ST 限幅改为 10%（实测：最后一个 5% 封板日 2026-07-31；8 月后被标 ST 的票出现 10% 封板 191 行 / 83 只，如 600243 2026-11-23 +10.08%），此后 ST 与普通股价格上不可区分；③ 段内偶有未触板日并入，给的是区间不是逐日真值。

三、正确的工程做法：三态，不是布尔

st_state(code, date) ∈ { KNOWN_ST, KNOWN_NORMAL, UNKNOWN }

UNKNOWN 的来源优先级：
  ① 自建每日快照（今天起，前向积累）
  ② 价格下界重建（只给 KNOWN_ST，2021 起）
  ③ 其余 = UNKNOWN

下游：只对 KNOWN_NORMAL 放行；KNOWN_ST / UNKNOWN 一律剔除或报错
      ——「未知当正常」是最贵的默认值

回测报告里必须打一行覆盖度：剔除ST：已知正常 X% / 已知ST Y% / 未知 Z%。Z 有多大是可以量化的，别省略。

四、顺手钉死两个会错的细节

涨跌停价取整不能用 float。对 1.00–50.00 元共 4,900 个前收价逐位比对 Decimal 半进位与 round(float)：涨停价 64/4,900 (1.3%) 不一致（前收 1.15 → 应 1.27，float 给 1.26），跌停价 174/4,900 (3.6%) 不一致（前收 1.25 → 应 1.13，float 给 1.12）。一分钱决定封板/未封板，进而决定能否成交。

日频「涨停不能买」错 1/3。主板 2021-01-04→2026-11-26：涨停触板 118,179 次，全天封死 78,937、盘中开板过 39,242（33.21%）；跌停触板 46,742 次，封死 26,390、开板 20,352（43.51%）。接口至少返回 SEALED / LIKELY_FILLABLE / UNKNOWN 三态。
