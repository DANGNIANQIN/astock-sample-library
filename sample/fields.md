数据截至：**2026-11-27**（每交易日 16:50 后更新） ｜ 区间：2025-01-02 ~ 2026-11-27
样本量：**33,293 只(股×涨停日)**，覆盖 461 个交易日、日均 72.2 只涨停 ｜ 题材层 69,529 行 / 249 个题材

## 一、这两个表解决什么问题

原始涨停明细只告诉你「谁涨停了、几板」，不告诉你「**为什么是这个板块在动、谁带的队**」。
这两张表把每个涨停**归因到一个具体题材**，并给出该题材当日的**强度、梯队、龙头**，让你判断：
这只票是主线里的跟风、是独苗妖股、还是纯粹被宽基概念顺手带进去的。

## 二、涨停题材归因_2025-2026.csv（个股层，33,293 行）

| 字段 | 含义 | 口径 / 怎么算的 |
|---|---|---|
| 代码 / 名称 | 股票代码、简称 | 代码 6 位纯数字；名称取本地股票表（缺 16 只，多为已退市/新上市） |
| 交易日 | 涨停日 | 交易所交易日 |
| 连板数 | 当日是该段连板的第几板 | 用完整交易日序列上「涨停日序号 − 段长」分段，再段内编号；跨周末/停牌不会断段 |
| 一字板 | 是否一字板 | 开盘即涨停且全天未开板 |
| 是否ST | 是否 ST/*ST | ST 股也有涨停，但**「ST板块」是财务状态的集合、不是题材**，ST 票的归因仅供参考 |
| 成交额(元) | 当日成交额 | 交易所口径 |
| **归因类型** | 主线 / 梯队 / 弱跟风 / 孤立 | 见第四节，用「题材涨停率 + 梯队」双判据 |
| **主归因题材** | 这只票当日主要归属的题材 | 从该股命中的全部题材里，按**题材当日涨停率**排序取第一（见第三节） |
| 主归因题材涨停率 | 该题材当日涨停家数 ÷ 题材成分数 | 例 0.0550 = 该题材 109 只成分里有 6 只涨停。**这才是「题材在动」的度量** |
| 主归因题材成分数 | 该题材成分股数 | 本地板块成分表 |
| 主归因题材是否截断 | 0/1 | 1 = 该题材成分恰达 400，属通达信板块文件 **400 槽上限截断**，成分不全、涨停家数会低估 |
| 该题材当日涨停家数 | 该题材当天几只涨停 | 由涨停明细 × 成分表现场算出 |
| 该题材当日最高连板 | 该题材内当日最高连板数 | 梯队高度的直接指标 |
| 该题材3板及以上家数 | 3 板+ 的只数 | 梯队厚度的指标 |
| 该题材当日一字板家数 | 一字板只数 | 强度/抢筹的指标 |
| 该题材涨停成交额占全场比 | 题材内涨停股成交额 ÷ 当日全部涨停股成交额 | 资金集中度 |
| 题材强度分位 | 该题材当日涨停家数在当日全部题材中的百分位 | 0.98 = 当日最强档 |
| 题材当日排名 | 按涨停家数的当日排名 | 1 = 当日涨停家数最多 |
| 当日有涨停题材数 | 当日出现涨停的题材总个数 | 分母，便于判断分位 |
| 本股在题材内强度位次 | 1 = 该股就是这个题材当日最强的（连板最高，并列取成交额大） | 龙头位次 |
| 命中题材数 | 该股一共属于多少个题材 | 中位 5、最多 36 —— 概念板块天然重叠，所以**必须给主归因，不能只列清单** |
| **是否题材龙头** | 0/1 | 1 = 该股在其主归因题材内连板最高 |
| 次日收益% | 次日收盘相对涨停日收盘 | 次日开盘买入算的是另一口径，此列为「持有到次日收盘」参考，不是可交易收益 |
| 次日是否再涨停 | 0/1 | 题材接力的直接证据 |

## 三、为什么主归因按「涨停率」而不是「涨停家数」

绝对家数会系统性偏向大板块：「一带一路」「人工智能」「物联网」成分都是 400 只，随便哪天都有 8~10 只涨停，
永远排在「人形机器人」（80 只成分，3 只涨停）前面 —— 但后者才是真正在动的那个题材。

所以主归因排序是：**先排除截断题材（成分≥400），再按涨停率排序，同率看最高连板**。
这就是「归因于谁」的答案：不是家数最多的题材，而是**被点燃得最充分**的题材。

## 四、四种归因类型的判据（写死、可复算）

| 类型 | 判据 |
|---|---|
| **主线** | 题材当日涨停率 ≥ 5% 且 涨停家数 ≥ 3，**或** 最高连板 ≥ 3 且 涨停家数 ≥ 3 |
| **梯队** | 涨停家数 ≥ 3（成队，但未达主线强度） |
| **弱跟风** | 涨停家数 = 2 |
| **孤立** | 涨停家数 ≤ 1 —— **该题材当天只有这一只涨停 = 个股独立事件**（公告/重组/业绩），不是题材行情 |

「孤立」是这套表最值钱的标签：连板越高却越孤立，说明是妖股独走，没有板块承接，风险结构与主线跟风完全不同。

## 五、题材强度日度_2025-2026.csv（题材层，69,529 行）

按「题材 × 交易日」给出当日强度面板，只保留当日有涨停的题材行。字段与上表同源，额外含：

- 其中首板家数、2 板家数、3 板及以上家数 → 梯队结构
- 题材龙头代码 / 龙头连板 / 龙头名称 → 当天谁在带队
- 次日涨停股均收益% / 次日再涨停率 → **题材次日接力能力**（99.8% 行有值）

## 六、已知缺陷与边界（不藏）

1. **题材映射只有 249 个**（本地通达信概念板块），不是全市场概念库；细分度取决于该板块表，冷门题材可能没有对应条目。
2. **400 槽截断**：成分恰等于 400 的 10 个题材（一带一路/人工智能/物联网/芯片/智能机器/储能/锂电池/含可转债/国防军工近 400/光伏 495）成分被板块文件上限截断，涨停家数偏低估 —— 已用「是否截断」列标出，且不参与主归因排序。
3. **覆盖 95.4%**：2025 起 34,457 只涨停里，1,575 只（4.6%）没有任何题材命中（新股、退市整理、冷门小票），这些不出现在本表。
4. **不做题材「纯度/真伪」判定**：同一个概念板块里既有真龙头也有蹭概念的，本表不判断谁是真受益标的。
5. **次日收益是收盘口径**，不能直接当可交易收益；A 股 T+1，涨停当日买不进也卖不出（一字板尤其）。
6. **不荐股、不预测、不承诺收益**。这是数据整理，不是投资建议。
7. 全部「题材当日强度」都是本表**自算**的（涨停明细 × 成分表现场聚合），不依赖任何第三方派生表 ——
   本地原有一张 `theme_stage` 派生表近期 lu_cnt 全为 0（2026-11-26 全空），已弃用，不复用。

## 八、这套标签实测有多少区分力（自己先打一次脸）

用全样本 33,293 条算「次日是否再涨停」，结果如下 —— **不美化，直接给**：

| 分组 | n | 次日再涨停率 | 次日均收益(收盘口径) |
|---|---|---|---|
| 主线 | 17,364 | 23.3% | +0.02% |
| 梯队 | 7,902 | 19.5% | +0.02% |
| 弱跟风 | 4,655 | 21.9% | +0.02% |
| 孤立 | 2,961 | 21.3% | +0.01% |

**结论一：归因类型本身几乎没有区分力**（23.3% vs 21.3%），控制连板数后更平。
所以「主线/孤立」是**结构描述**，不是涨跌预测 —— 别拿它当买卖信号。

| 分组 | n | 次日再涨停率 |
|---|---|---|
| **主线里的题材龙头** | 2,909 | **34.7%** |
| 主线里的非龙头 | 14,455 | 21.0% |
| 梯队里的龙头 | 1,405 | 24.3% |
| 孤立（本身就是龙头，无跟随） | 2,961 | 21.3% |
| 1 板 | 25,626 | 17.2% |
| 2 板 | 4,415 | 33.4% |
| 3 板 | 1,478 | 46.4% |
| 6 板以上 | 363 | 56.5% |

**结论二：真正有区分力的是「是否题材龙头」（34.7% vs 21.0%，差 13.7pp）和连板高度**，
题材归因的价值在于**判断这只票是不是带队的那一个**，而不是给它贴「主线」两个字。

**结论三：次日均收益全部≈0**（+0.01~+0.03%），因为这是「涨停日收盘 → 次日收盘」口径，
本身就接近无套利，且涨停价买不进。要看收益必须用可成交口径单独回测，本表不提供收益结论。

## 十一、涨跌幅上限重建（2026-11-27，v2）

本包第一版把行情接口里的 `limit_pct` 直接当涨跌幅上限用，而那个字段是由 `is_st`
（「当前股票名称是否含 ST」的静态回填）推出来的。实测双向都错：

| 方向 | 事实 | 后果 |
|---|---|---|
| 现在叫 ST 的票 | 全历史标 ST，312 只里 0 只有过摘帽 | 非 ST 期间按 5% 判涨停，+10% 的日子被错记成涨停、错标「一字板」 |
| 现在不叫 ST 但历史 ST 过 | 261 只 / 5,918 天该标未标 | 5% 封板日 close 达不到 10% 目标价，**整行丢失** |

改用价格证据重建上限（主板）：2026-08-03 起一律 10%；否则 ±10 日窗口内出现过 >5.15% 的日涨跌幅 ⇒ 10%；
否则窗口内 ±5% 命中 ≥2 天 ⇒ 5%（= 当日为风险警示股）。另加封板守卫：close 必须落在涨停价
[-0.01, +0.02] 元内，超出说明上限推定错或当日无涨跌幅限制，不计涨停。

对本包的实际影响（同一份底层数据对账，v1/v2 为迁移时点 2026-11-26 的值；当前值见文首）：

| 指标 | v1 | v2 |
|---|---|---|
| 个股层行数 | 33,611 | **32,882** |
| 题材层行数 | 69,802 | **69,305** |
| 其中「ST（价格证据）」行 | —— （v1 用静态 is_st：5,377） | **3,131** |
| 价格判定非涨停的假行 | 未度量 | **325 行（1.0%）** |

判据可复算：`ST价格证据=1` 的行，其收盘价必须等于 `round(前收×1.05, 2)`（±2.5 分内，源自
浮点四舍五入）；本包 3,131 行全部满足。重建脚本 `rebuild_limit_up_cap.py`，与售卖的
「涨停连板数据库」同一套口径，两个包的 `cap_evidence` 可直接对齐。
