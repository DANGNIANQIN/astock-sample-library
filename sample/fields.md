# A股涨停 / 连板数据库（2021-01 起）

- 区间：2021-01-11 起，每天收盘后重建到最新交易日（今天是最新一根）
- 明细行数 / 交易日数：**每天在变**，准确数以同站点 `/live/meta.json` 的 `rows` / `trading_days` / `last_trade_date` 为准（机器生成，与 CSV 逐行一致）
- 历史极值（不随更新变化）：单日最多 **959** 只涨停（2024-09-30）；最高连板 **25** 板（600112，2021-07-08）

## 文件

| 文件 | 内容 |
| 涨停明细_2021-2026.csv | 每行 = 一只涨停股一个交易日：价格、成交额、换手、几板、是否一字板，以及**次日开盘溢价/最高/收盘/是否继续涨停**全部算好 |
| 连板统计.csv | 按「第几板」分组：样本数、平均/中位开盘溢价、次日收益、次日涨停率、收盘胜率、一字板占比 |
| 情绪日度.csv | 每个交易日的涨停家数、连板家数、一字家数、最高连板、涨停股总成交额、平均换手、次日涨停率 |
| 示例_读数据.py | 用 pandas 直接读三张表并打印常用统计，改个日期就能跑 |

## 字段（涨停明细）

| 字段 | 含义 |
|---|---|
| `code` | 股票代码（6 位，如 002164） |
| `date` | 交易日 YYYY-MM-DD |
| `board` | 板块：MAIN=主板 / GEM=创业板 / STAR=科创板 / BJ=北交所 |
| `is_st` | 当日是否为 ST（true/false） |
| `close_raw` | 当日收盘价（未复权，元） |
| `limit_price` | 当日涨停价 = round(前收 × (1+limit_pct), 2)，未复权 |
| `amount` | 当日成交额（元） |
| `turnover` | 当日换手率（百分数口径，6.18 = 6.18%） |
| `is_one_word` | 1=一字板（开=高=低=涨停价），0=换手板 |
| `streak` | 当日是第几连板（1=首板） |
| `next_open_gap` | 次日开盘相对当日收盘的溢价（小数，0.052 = +5.2%） |
| `next_high_pct` | 次日最高相对当日收盘涨幅（小数） |
| `next_close_pct` | 次日收盘相对当日收盘涨幅（小数） |
| `next_is_limit` | 1=次日继续涨停，0=未涨停 |

## 口径说明（重要，别猜）

1. **涨停判定用未复权价**：`close_raw >= round(preclose_raw*(1+limit_pct), 2) - 0.001`。用复权价判涨停会在除权日漏判，本表不含复权价字段。
2. **`limit_pct` 已按规则分段**：主板 10%；创业板/科创板 20%；北交所 30%；ST 在 2026-08-01 之前为 5%、之后为 10%；新股上市前 5 日不限涨跌幅（不在此表）。
3. **次日字段是「相对当日收盘价」**，不是相对次日开盘：`next_open_gap` 就是次日开盘买、当日收盘卖的毛利，扣手续费/滑点前。A 股 T+1，当天买入不能当天卖出，所以「当日收盘买入、次日开盘卖出」才是合法口径。
4. **最后一个交易日的次日字段为空**（还没发生），不要当 0 处理。
5. **连板数**按该股票自身的连续涨停计算，跨周末不断板；**跨停牌也连续计数**——只要该票下一个有成交的交易日仍是涨停，就接着数。实例（可复核）：603226 菲林格尔 2025-05-30 首板（8.22）→ 06-03 全天停牌（交易所正常开市、全市场 5,380 只有成交，但该票当日无 K 线、无成交）→ 06-04 一字 9.04、06-05 9.94、06-06 10.93，本表记为 **06-06 = 4 板**。有些实现遇到缺 K 线就断板、会把这只算成 3 板，买之前先问清对方是哪种口径。
6. 成交额/换手为交易所口径原始值；换手率是百分数（6.18 = 6.18%），不是小数。

## 已知边界（写清楚，不藏）

- 没有**涨停时间**和**封单额**：日线数据先天没有盘中封板时间。封单额只有 2026-11 起的新增字段，本包不含（样本期太短，单独给会误导）。
- 没有**炸板率**的分钟级口径：只能从「最高价是否触及涨停 + 收盘未涨停」近似，本表未做，需要的话自己用 high_raw / limit_price 判。
- 2021 年前的涨停不在本包内（数据从 2021-01 起）；2021-01-04 当天因数据源覆盖不完整（仅 1 条）已剔除，本包首日为 2021-01-11。

## 能拿它做什么（以及不能做什么）

能做：验证「几板之后次日胜率多高」「一字板和换手板差多少」「小成交额是不是更容易连板」「每天涨停家数和次日涨停率的关系」这类可复算的问题；给自己的策略做基准线。

不能做：这不是选股建议。历史统计不保证未来，本包不含任何「该买什么」的结论，也不承诺收益。任何策略都要自己扣手续费、印花税、滑点后重算。

## 复算校验

全表行数与交易日区间**每天在变**，以同站点 `/live/meta.json` 的 `rows` / `trading_days` / `last_trade_date` 为准（那份是机器生成、与 CSV 逐行一致）。本文件刻意不写死数字——写死就会像之前那样出现「页面说 100,821、你数出来 100,820」。区间起点固定为 2021-01-11。若你数出来的行数与 meta.json 不一致，说明文件被改过。

> `is_st` 取自本地简称表，新戴帽/摘帽可能滞后 1–2 个交易日。2026-08 起主板 ST 涨跌幅也是 10%，滞后不影响涨停判定；2026-08 前 ST 为 5%，历史段请以行情简称复核。
> 家数口径：本表包含 ST；东财「涨停池」默认剔除 ST（2026-11-25 我们 58 家 / 东财 51 家，差额 7 家均为 ST）。
