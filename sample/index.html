import pandas as pd
df = pd.read_csv("limitup_sample_30d.csv", parse_dates=["date"])
df.groupby("date")["code"].count().tail()        # 每日涨停家数
df.groupby("streak")["code"].count()             # 连板梯队分布（1=首板）
df[["next_open_gap","next_close_pct"]].describe()  # 次日开盘跳空 / 次日收盘收益分布
字段（14 列，逐列对上文件头）
列含义
code / date / board6 位代码、交易日、板块（MAIN 主板 / GEM 创业板 / STAR 科创板 / BSE 北交所）
is_st是否 ST（涨跌幅 2026-08 起 10%、此前 5%）
close_raw / limit_price未复权收盘价、当日涨停价（四舍五入到分，判断封板用这一对）
amount / turnover成交额(元)、换手率(%)
is_one_word / streak是否一字板、截至当日的连板高度（1=首板）
next_open_gap次日开盘相对当日收盘的跳空（小数，0.03=高开 3%）
next_high_pct / next_close_pct次日最高价 / 次日收盘 相对当日收盘（小数）
next_is_limit次日是否再次涨停（1/0；最后一个交易日为 0 是因为次日尚无数据，不要当成「不会涨停」）
口径：涨停按未复权价与前收计算（close_raw >= round(preclose*(1+limit_pct),2)-0.001）；连板用 gaps-islands 法（涨停日序号 − 段内序号），跨周末不会断。
