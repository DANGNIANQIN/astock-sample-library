# 历史 ST 区间表：覆盖率与 v1 错处对账

生成：`build_st_intervals_v2.py`（纯 stdlib + duckdb 只读，2026-11-27）
覆盖时代：**2021-01-04 ~ 2026-07-31**（主板 ST 限幅 5% 时代。2026-08-03 起 ST 也是 10%，
价格不可区分，本表对该区间不出结论）

## 一、本版给什么

| 项 | 值 |
|---|---|
| 可证实 ST 连续段 | **902 段** |
| 涉及股票 | **414 只** |
| 可证实 ST 交易日 | **9527 天** |
| 证据 | `price5`：收盘封在 5% 涨停价 + ±10 交易日窗口 max\|涨跌幅\| ≤ 5.15% + 同段 ≥2 天 |
| 假阳性标定 | 20 只从未 ST 白马命中 **0** 只 |

**这是下界，不是全集。** ST 日是「只能被证实、不能被穷举」的量：一只 ST 票若整段从未封过
5% 涨停，价格上不留任何痕迹，本表不会收录。**拿本表做「剔除 ST」会漏掉未被证实的票**——用它
过滤候选池必须同时声明这一点；要全覆盖只能存当日名单快照（即日起每日落盘，不可回溯）。

## 二、v1（静态 `is_st` 回填版）错在哪

| 指标 | v1 静态表 | 本版（价格证据） |
|---|---|---|
| 股票数 | 312 只 | 414 只 |
| 段数 | 312 段（每只仅 1 段、0 只摘帽 = 静态指纹） | 902 段 |
| 声称的 ST 日 | 367586 天 | 9527 天（仅可证实部分） |
| **可证伪行** | **51901 天 / 286 只**（当天 \|涨跌幅\| > 5.15%，ST 限幅下不可能） | 0（自检⑤） |

三类错：

1. **无任何价格证据 159 只**（其中 **133 只**在 v1 声称的 ST 段内确实
   出现 \|涨跌幅\| > 5.15% 的日子 = 至少那段标错；余下 **26 只**既不可证实也不可
   证伪 = 不可判定，不判它假阳性）。典型是「现在叫 ST、当年不叫」，被整段回填。
2. **假阴性 261 只**：价格证据明确显示 5% 限幅运行，但当前名称不含 ST，v1 整段漏标。
3. **可证伪 51901 天**：v1 声称这些天是 ST，而当天涨跌幅超过 5.15%——不依赖任何外部源，
   用 v1 自己的表加行情即可推翻。

两者都命中的只有 **153 只**（占 v1 的 49%）。

## 三、回滚

互换：v1 列 `trading_days`，本版列 `confirmed_days` + `evidence`。
